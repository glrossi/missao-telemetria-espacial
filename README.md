# 🚀 Projeto de Telemetria e Decisão de Decolagem Espacial

## 📌 Descrição do Projeto
Este repositório contém o sistema de análise de telemetria, verificação de parâmetros de segurança para decolagem e cálculo de autonomia energética desenvolvido para a Atividade Integradora.

## 🛠️ Tecnologias Utilizadas
- Python 3.x
- Jupyter Notebook
- Git & GitHub

## 📂 Conteúdo do Repositório
- `notebook.ipynb`: Notebook com o código Python executável e memória de cálculo.
- `README.md`: Documentação e apresentação do repositório.

## ⚙️ Como Executar o Código
1. Abra o arquivo `notebook.ipynb` diretamente no GitHub ou importe para o [Google Colab](https://colab.research.google.com).
2. Execute cada célula sequencialmente para verificar a saída do relatório de telemetria.
